# First Release

First playable version of the game.

## Features

- Pixel art ARPG gameplay
- Enemy combat system
- Inventory system
- UI and item interactions

## Controls

- WASD - Move
- J - Attack
- ESC - Pause
- L - Boomerang
- P - Talk With NPC
- K -Interaction

## Notes

- Download and unzip the file
- Run the .exe to play
